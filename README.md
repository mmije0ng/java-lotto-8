# java-lotto-precourse
## ✨ 기능 목록

### 1. 로또 구입 기능
- [ ] "구입금액을 입력해 주세요." 문구를 출력하여 사용자에게 입력을 유도한다.
- [ ] 사용자가 입력한 금액을 정수로 변환한다.
- [ ] 금액이 1,000원 단위인지 검증한다.
- [ ] 금액이 1,000 미만이거나 1,000으로 나누어 떨어지지 않으면 예외를 발생시킨다.
- [ ] 입력한 금액에 따라 구매 가능한 로또 개수를 계산한다.
- [ ] "n개를 구매했습니다." 문구를 출력한다.

### 2. 로또 발행 기능
- [ ] 1~45 사이의 중복되지 않은 6개의 숫자를 랜덤으로 생성한다.
- [ ] 생성된 숫자를 오름차순으로 정렬한다.
- [ ] 구매한 로또 개수만큼 로또를 생성하여 저장한다.
- [ ] 각 로또의 번호를 출력한다.  
  예: `[8, 21, 23, 41, 42, 43]`

### 3. 당첨 번호 입력 기능
- [ ] "당첨 번호를 입력해 주세요." 문구를 출력하여 사용자에게 입력을 유도한다.
- [ ] 사용자가 입력한 번호를 쉼표(,)로 구분하여 List<Integer>로 변환한다.
- [ ] 중복된 번호가 없는지 검증한다.
- [ ] 각 번호가 1~45 범위 내에 있는지 검증한다.
- [ ] 유효하지 않은 번호가 포함된 경우 예외를 발생시킨다.

### 4. 보너스 번호 입력 기능
- [ ] "보너스 번호를 입력해 주세요." 문구를 출력하여 사용자에게 입력을 유도한다.
- [ ] 사용자가 입력한 보너스 번호가 1~45 범위 내에 있는지 검증한다.
- [ ] 당첨 번호와 중복되지 않는지 검증한다.
- [ ] 중복되거나 범위를 벗어난 경우 예외를 발생시킨다.

### 5. 당첨 결과 판별 기능
- [ ] 사용자가 구매한 각 로또의 번호를 당첨 번호와 비교한다.
- [ ] 일치한 번호의 개수를 계산한다.
- [ ] 일치한 개수와 보너스 번호 일치 여부에 따라 등수를 판별한다.
- [ ] 당첨 기준 및 상금은 다음과 같다.
  | 등수 | 조건 | 상금 |
  |------|------|------|
  | 1등 | 6개 번호 일치 | 2,000,000,000원 |
  | 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
  | 3등 | 5개 번호 일치 | 1,500,000원 |
  | 4등 | 4개 번호 일치 | 50,000원 |
  | 5등 | 3개 번호 일치 | 5,000원 |

### 6. 결과 출력 기능
- [ ] "당첨 통계" 문구를 출력한다.
- [ ] 각 등수별 당첨 개수를 출력한다.  
  예: `3개 일치 (5,000원) - 1개`
- [ ] 수익률을 계산한다.
    - 총 당첨 금액 ÷ 구입 금액 × 100
    - 소수점 둘째 자리에서 반올림한다.
- [ ] "총 수익률은 X%입니다." 형식으로 출력한다.

### 7. 프로그램 실행 흐름
1. [ ] 로또 구입 금액 입력 → 검증
2. [ ] 로또 번호 자동 발행 → 출력
3. [ ] 당첨 번호 입력 → 검증
4. [ ] 보너스 번호 입력 → 검증
5. [ ] 당첨 결과 판별 → 등수별 개수 계산
6. [ ] 결과 및 수익률 출력

## ⚠️ 예외 처리 조건

### 1. 입력 예외
- [ ] 구입 금액이 숫자가 아니거나 1,000으로 나누어 떨어지지 않는 경우  
  `[ERROR] 구입 금액은 1,000원 단위여야 합니다.`
- [ ] 당첨 번호 입력 시 숫자가 아닌 값이 포함된 경우  
  `[ERROR] 로또 번호는 숫자여야 합니다.`
- [ ] 당첨 번호가 6개가 아닌 경우  
  `[ERROR] 로또 번호는 6개여야 합니다.`
- [ ] 번호가 1~45 범위를 벗어나는 경우  
  `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`
- [ ] 당첨 번호에 중복이 존재하는 경우  
  `[ERROR] 중복된 당첨 번호가 존재합니다.`
- [ ] 보너스 번호가 1~45 범위를 벗어나거나 당첨 번호와 중복된 경우  
  `[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.`

### 2. 실행 예외
- [ ] 위 조건 중 하나라도 위반 시 `IllegalArgumentException`을 발생시킨다.
- [ ] 예외 메시지는 반드시 "[ERROR]"로 시작한다.
- [ ] 에러 발생 시 해당 단계부터 입력을 다시 받는다.
